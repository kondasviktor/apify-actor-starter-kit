Quick start

git clone https://github.com/kondasviktor/apify-actor-starter-kit.git
cd apify-actor-starter-kit
npm ci
npm test
npm run build
# optional: apify login && apify run

Deploy privately: npm run build → apify login → apify push (separate commands). Slug from .actor/actor.json.

What it does

Catalog URLs → optional pagination → detail pages for UPC, category, description. Charges once at start and per dataset row (capped by maxItems).
